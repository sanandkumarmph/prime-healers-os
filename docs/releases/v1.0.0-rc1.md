## Testing Checklist

Run before UAT merge:

```bash
npm run build
php artisan test
```

Recommended smoke checks:

- Dashboard loads and Executive Command Center trend cards show comparison labels.
- Rental create saves an in-house rental with assigned assets and a vendor-supplied rental.
- Sale create saves direct and vendor-supplied sales.
- Renewal Center cards and actions work on desktop and mobile.
- Deliveries / Tasks Board actions remain clickable.
- Inventory Intelligence, Asset Register, Product Master, and Stock History load without layout overflow.
- Invoice Center filters are collapsed by default and invoice actions work.
- Company Settings asset upload previews work.
- Roles and Dashboard Configuration save expected changes.
- Data Import templates download and upload flow opens.
- Business Partners list, actions, and filters work.

## Deployment Steps

Do not merge to UAT until this checkpoint branch and tag are reviewed.

When approved:

```bash
git checkout uat
git pull origin uat
git merge --no-ff ui-stabilization-uat-20260707
git push origin uat
php artisan migrate --force
php artisan storage:link
php artisan optimize:clear
```

Run any environment-specific cache and queue restart steps required by UAT.
